영단어 암기 게임 – 실행 방법

[처음 한 번만] Node.js 설치
1. https://nodejs.org 에서 "LTS" 버전을 내려받아 설치합니다(다음 → 다음 → 설치).
2. 설치가 끝나면 PC를 한 번 껐다 켜거나, 열려 있던 명령 창을 모두 닫습니다.

[1] 그냥 해 보기(개발용) – 앱실행.bat
  - 이 폴더(word-game)에서 "앱실행.bat"을 더블클릭합니다.
  - 처음에는 필요한 프로그램을 내려받느라 1~3분 걸립니다(npm install).
  - 브라우저가 열리고 "영단어 암기 게임" 홈 화면이 보입니다.
  - 이 방식은 오프라인 기능이 꺼져 있습니다(개발용).

[2] 앱으로 설치 · 인터넷 없이 쓰기 – 앱설치_오프라인실행.bat
  1. "앱설치_오프라인실행.bat"을 더블클릭합니다(빌드 후 http://localhost:4173 이 열림).
  2. 홈 화면 아래에 "✓ 오프라인에서도 사용할 수 있어요"가 보이면 준비 완료입니다.
  3. 크롬/엣지 주소창 오른쪽의 [설치] 아이콘 또는 홈 화면의 [📲 앱으로 설치] 버튼을 누르면
     바탕화면·시작 메뉴에 "영단어게임" 앱이 생깁니다.
  4. 한 번 열어 둔 뒤에는 인터넷이 끊겨도 앱이 열리고 학습 기록도 그대로 저장됩니다.
     (설치한 앱은 검은 명령 창을 닫아도 열립니다. 다만 새 버전을 받으려면 이 bat을 다시 실행하세요.)
  5. 새 버전이 나오면 화면 위에 "새 버전이 준비됐어요 [새로고침]"이 뜹니다. 누르면 바뀌고, 학습 기록은 그대로입니다.

[휴대폰]
  - 휴대폰 설치·오프라인은 보안 주소(https://)에서만 됩니다. PC의 http 주소로는 휴대폰 설치가 되지 않습니다.
  - 인터넷 주소(https)에 올리는 일은 다음 개발 단계에서 안내합니다.

[학습 기록]
  - 기록은 이 기기·이 브라우저 안(IndexedDB)에 저장됩니다. 브라우저 방문 기록 "모두 삭제"를 하면 지워질 수 있습니다.

[명령어로 하고 싶을 때] 이 폴더 주소창에 cmd 입력 → Enter → 아래를 차례로 복사해서 실행
  npm install
  npm run dev -- --open                (개발용)
  npm run build                        (앱 만들기)
  npm run preview -- --port 4173 --open (만든 앱 열기 · 오프라인 · 설치)
